# Instrucciones para Codex

Este repositorio contiene módulos personalizados para Odoo 19 Community.

## Traducciones

- El idioma objetivo es español de México: es_MX.
- Cada módulo debe conservar su propio archivo i18n/es_MX.po.
- No crear un archivo PO global.
- Mantener intactos los msgid.
- Traducir únicamente los msgstr.
- Conservar placeholders, etiquetas, saltos de línea e identificadores.
- Utilizar terminología coherente con Odoo en español.
- No modificar lógica de negocio durante tareas de traducción.
- No modificar modelos, vistas, ACL, reglas de acceso, datos ni versiones.
- Validar los archivos con msgfmt --check.
- Reportar entradas ambiguas o marcadas como fuzzy.

## Terminología preferida

- asset: activo
- resource: recurso
- rental: renta
- quotation: cotización
- sales order: pedido de venta
- purchase order: pedido de compra
- manufacturing order: orden de fabricación
- project: proyecto
- task: tarea
- timesheet: parte de horas
